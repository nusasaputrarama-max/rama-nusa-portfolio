# Rama Nusa Saputra — Portfolio

Website portofolio statis berbahasa Indonesia. Dibuat dengan HTML, CSS, dan JavaScript tanpa framework/build step.

## Menjalankan secara lokal
Buka `index.html` di browser, atau jalankan server statis dari folder ini:

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000`.

## Deploy gratis ke Vercel
1. Buat repository GitHub baru dan unggah seluruh isi folder ini.
2. Masuk ke Vercel dan pilih **Add New → Project**.
3. Import repository tersebut.
4. Untuk framework pilih **Other**; Build Command dan Output Directory dapat dikosongkan (root proyek).
5. Klik Deploy. Vercel akan memberikan subdomain gratis `*.vercel.app`.

## Sebelum dipublikasikan
- Periksa kembali nomor WhatsApp, email, dan tautan Instagram.
- Tambahkan dokumentasi visual De Kicen pada bagian proyek.
- Tambahkan artikel/opini asli pada bagian Karya Jurnalistik setelah memilih sampel yang boleh dipublikasikan.
- Pastikan penyebutan pengalaman, tanggal, dan kontribusi sudah akurat.

## Struktur
- `index.html` — konten website
- `style.css` — desain responsif dark minimalist
- `script.js` — navigasi mobile
- `assets/profile.png` — foto profil yang diberikan
